# Phase 3AI — Pinned Privileged Writer Source Review (NOT Global Enforcement)

Date: 2026-10-21 Asia/Bangkok. Scope: source-only GitHub code/CI, unexported. **No Firebase deploy, runtime policy change, real money mutation, or accounting certification.**

## Goal and boundary
Phase3AH counted direct `paymentStatus: "paid"` literals and verified selected guards, but new writes using variables or quoted/computed keys could evade that specific check. Phase3AI adds `functions/hybrid-billing-phase3ai-privileged-ingress.js`, an isolated audit module that pins actual Git Blob SHA1 of eight existing source files and inventories direct mutation *syntax* in all non-Hybrid top-level `functions/*.js` source files. `index.js` itself is pinned to prevent unnoticed re-export of Finance candidate modules. Changed reviewed bytes or new recognized keys fail CI and mandate human source review before updating the review baseline.

Eight SHA-pinned entrypoint/inventory files: `index.js`, `delivery-slip.js`, `operational-orders.js`, `public-delivery-submit.js`, `lalamove-order-lifecycle.js`, `lalamove-webhook.js`, `retail-pos-backup.js`, and `hybrid-billing-legacy-payment-guard.js`. The lexical inventory counts key:value literals, quoted or constant computed keys, and direct object member assignments for `paymentStatus`, `paidAt`, `refundTotal`, `refundAmount`, and `paymentReceiptSource`. Only reviewed baseline counts are allowed. It strips JS comments before scanning. Source-level all-clear always returns `runtimeEnforcement:false`, `unknownAdminSdkRoutesClosed:false`, `writerParticipationComplete:false`, `sourceCompletenessProven:false`, `coverageCertified:false`, `canMarkPaid:false`, `canIssueInvoice:false`.

This mechanism does not hook Firestore writes or Cloud Admin SDK, does not review arbitrary client rules/REST/deployed Firebase, and does not detect all indirect runtime write patterns: aliases to computed field names, spreads, schema-driven transforms, dynamic modules, outside-the-repo pipelines, Admin SDK data migrations, or altered CI scripts can bypass source scanning.
